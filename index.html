Welcome To Student Hub Portal

Student Hub Portal is a unified digital academic platform designed for college students, faculty, and administrators. It streamlines course registration, academic performance monitoring, event participation, profile management, and two-way institutional communication in one secure, accessible interface.


Core Integrated Features

📝 Online Registration

Self-service student account registration with server-side validation and password hashing.

🔐 Secure Authentication

Session-based login with role-based access control (Student vs. Administrator).

📊 Live Dashboard

Real-time academic performance, registered courses, attendance tracking, and CGPA overview.

🎉 Campus Events

Interactive event registrations with instant AJAX feedback and participation status.

👤 Student Profile

Dynamic profile updates, personal details, contact information, and academic credentials.

🛡️ Admin Control

Dedicated administration dashboard for managing students, tracking inquiries, and auditing feedbacks.
