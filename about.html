Who We Are?

Student Hub Portal is a modern, responsive full-stack web application developed for the ITUE203 Web Development Frameworks course at Chandubhai S. Patel Institute of Technology (CSPIT), CHARUSAT. The system bridges students, faculty, and administrative departments, eliminating repetitive paperwork and providing transparent, 24/7 access to student services.

Our Mission & Vision

🎯 Our Mission

To provide an intuitive, high-performance, and secure digital environment where university students can seamlessly track academic milestones, participate in co-curricular events, and communicate with institutional authorities.

🔭 Our Vision

To pioneer smart campus automation through full-stack web frameworks, incorporating modern responsive web design, robust server-side security, accessible UX (WCAG 2.1), and scalable database architectures.

Technology Architecture

Layer Technology Key Capabilities
Frontend HTML5, CSS3, Modern JavaScript (ES6+) Semantic tags, CSS Flexbox/Grid, Dark Mode, AJAX, WCAG 2.1 compliance
Backend PHP 8.x (Native & OOP) Session management, BCrypt password hashing, role-based access, CSRF defense
Database MySQL (MariaDB / InnoDB) Relational integrity, prepared statements (PDO), parameterized queries
Deployment Apache / XAMPP & GitHub Virtual Host (studenthub.local), version control, clean modular codebase
